# Проверка источников — 18 сентября 2026

> Исторический отчёт первоначальной проверки 33 источников. После проверки пользователь исключил Google Data Analytics, Fivetran, Jumpmind, Azure Data Factory, Dataddo, Streambed, GitLab, Selectel и Spotify для прямой подписки. В текущей конфигурации осталось 24 источника; результаты ниже сохранены как история проверки.

Все 33 источника проверены из собранного Docker-образа командой `-check`. Общий прогон: 30 успешных источников, две блокировки и одна ошибка DNS Claude. Повторная проверка Claude с DNS 1.1.1.1 успешна; эта настройка включена в Compose и переопределяется через DNS_SERVER.
У 31 источника обнаружены статьи; DBConvert и Databricks блокируют запросы Cloudflare.
Проверка полного текста выполнена для одной статьи каждого доступного источника на хосте с временным профилем Chromium-совместимого браузера. Это выборочная проверка, не гарантия извлечения каждой статьи.
Дополнительно внутри Docker полностью загружены 20 статей Google: RSS содержит 20 уникальных GUID и полный текст, XML/OPML корректны, RSS не изменился после пересоздания контейнера.

## Практические ограничения

- Работоспособность всех 33 источников пока не подтверждена: две внешние блокировки остаются. Проверка с IP пользовательского сервера может дать другой результат; используйте `-check -sample -source databricks` или `dbconvert`.
- Начальные 20 — верхний предел доступной выборки. CData и Tencent сейчас дают меньше 20; у Streambed и Ian Macomber на проверенных страницах меньше статей. Недобор отображается предупреждением при первой загрузке.
- Списки с featured/recommended материалами могут включать старые закреплённые статьи. Без даты в списке отбор использует порядок сайта; строгое соответствие последним 20 по дате не гарантируется для таких страниц. Извлечённые даты затем определяют порядок RSS.
- Для некоторых образцов не удалось определить дату публикации. В базе используется время обнаружения; поле не выдаётся за извлечённую дату оригинала.
- Изображения с удалённых сайтов могут быть недоступны читателю из-за hotlink-защиты.
- Автоматизация не решает CAPTCHA и не использует сторонние зеркала или платные прокси.

## Проверки программы

`go test -race ./...`, `go vet ./...`, `docker-compose config --quiet`, сборка Docker проходят.
Тесты покрывают сохранение SQLite после повторного открытия, ограничение 100, дедупликацию после очистки старых статей, отсутствие нежелательного архивного импорта на втором обходе, изоляцию сбоев, валидность RSS и OPML, ETag, очистку HTML, метаданные, пагинацию и проверку YAML.

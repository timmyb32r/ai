## Особенности адаптеров

- Digoal читает только официальный репозиторий. Из README выбирает до 100 уникальных статей с корректной датой `YYYYMM/YYYYMMDD_NN.md`; закреплённые старые ссылки не влияют на порядок. Markdown преобразуется в очищенный HTML, относительные изображения ведут на raw.githubusercontent.com, ссылки — на GitHub. Лента коммитов не используется, так как правка README не является новой статьёй. Даты имеют точность до дня.
- Mirrorship сортирует публикации после проверки дат страниц: порядок карточек и отдельный раздел не дают последние статьи всего блога. Одновременно загружаются не более четырёх статей, общий срок — 90 секунд, предел — 120 уникальных ссылок. При превышении предела или ошибке даты источник явно сообщает об ошибке и сохраняет прежнюю выдачу; требуется пересмотреть адаптер, а не обрезать список с неверной хронологией. Заголовок каждой страницы сверяется с карточкой: сайт иногда отдаёт тело другой статьи при параллельных запросах. Такие ответы перепроверяются последовательно в пределах того же срока; повторное несовпадение приводит к явной ошибке источника. После успешной сверки полный текст повторно не запрашивается.
- InfoQ использует публичные JSON API с обычными заголовками Referer/Origin. Документ статьи преобразуется из JSON в очищенный HTML с текстом, ссылками и изображениями. Авторизация и CAPTCHA не используются.
- Meituan отдаёт десять RSS-записей без дат. HTML содержит даты и более старые публикации; при объединении отсутствующие даты дополняются, содержимое RSS сохраняется.
- `title_selector` помогает не заменять название статьи общим заголовком сайта (CNBlogs, Timecho) и не включать анонс в заголовок (SelectDB, TAOS Data).

Регрессионные тесты подтверждают сохранение содержимого RSS при дополнении дат и правильное извлечение явного заголовка.

## Внешние ограничения

- Databend: канонический адрес с `www` правильный — вариант без `www` перенаправляет на него. Недоступность воспроизвелась затем и нативным HTTP-запросом; это текущая проблема соединения с CDN. Теперь источник исключён из сервера для прямой подписки в Inoreader.
- Aliyun: запросы с хоста временами перенаправлялись на страницу входа; проверка в Docker прошла без авторизации. Доступ может зависеть от адреса сервера и ответа сайта. При отказе источник сообщает об ошибке, остальные ленты продолжают работать.
- Mirrorship: предел в 120 обнаруженных статей является явным ограничением текущего адаптера; при росте блога потребуется обновить способ обхода.

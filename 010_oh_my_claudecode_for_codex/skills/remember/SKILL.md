# Remember

Classify each item before writing:
- durable repository rules belong in the applicable `AGENTS.md`;
- architecture or operational knowledge belongs in existing project docs;
- temporary task notes belong under `.agents/notes/`;
- reusable procedures may become a skill;
- secrets, personal data, transient logs, and unverified guesses must not be persisted.

Prefer updating an existing source of truth over creating a competing document. Keep entries concise, evidence-based, and scoped to the narrowest applicable directory. Report what was stored and where.

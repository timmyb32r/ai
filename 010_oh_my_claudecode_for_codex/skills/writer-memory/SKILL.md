# Writer Memory

Store structured Markdown or JSON under `.agents/writer-memory/` using stable entity IDs.

Track:
- characters: traits, goals, voice, arc, first/last appearance;
- relationships: direction, status, turning points;
- world rules: constraints, locations, chronology;
- scenes: viewpoint, time, place, participants, events, consequences;
- themes and unresolved threads.

Before adding facts, distinguish canon, draft proposal, inference, and contradiction. Never silently overwrite canon. For queries, cite the source scene or memory entry. Validate dialogue, chronology, location, knowledge, and relationship continuity. Generate synopses from stored facts and explicitly flag gaps.

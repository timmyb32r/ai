# External Context

1. Decompose the question into at most five independent facets when that improves coverage.
2. Prefer local source-of-truth documentation, then official primary sources, standards, and papers.
3. Browse whenever facts are current, niche, high-stakes, or explicitly requested.
4. Use parallel search queries when possible; use sub-agents only when the user explicitly requests delegation and tools are available.
5. Record source date/version and distinguish sourced fact from inference.
6. Resolve conflicts instead of averaging incompatible claims.
7. Return key findings, uncertainty, practical implications, and direct citations near each claim.
